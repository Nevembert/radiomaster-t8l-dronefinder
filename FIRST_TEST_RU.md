# Установка и проверка DroneFinder 1.0

Пользователь сообщил об установке 0.6. Следующие шаги относятся к новой
версии проекта 1.0: её звук пока не проверен на пульте.

1. Сохрани распакованный архив: в recovery есть 0.6 и заводская 1.7.
   Файлы не являются копией настроек. Текущие настройки зафиксируй скриншотами.
2. Дрон оставь выключенным. Подключи пульт в штатном режиме конфигуратора
   M+питание, USB; в официальном WebUI подключись к RadioMaster.
3. Firmware Update → T8L Controller → Start Firmware Update.
   После переподключения выбери пульт снова. В предупреждении о продолжении
   выбери OK. Откроется страница обновления.
4. Перетащи `build/T8L_v17_DroneFinder_1.0.bin` в поле
   прошивки. Не module.bin. Нажми Confirm Update. Не отключай USB/питание
   до сообщения об успешном завершении; при ошибке сохрани журнал.
5. После успеха, если остался режим обновления: Device → Exit Firmware Update,
   затем выключи пульт, отключи USB и включи обычным способом без M.
   Отсоединение кабеля само по себе не выводит из загрузчика.
6. Проверь обычное включение и прежние настройки/каналы. Поиск проверяется
   без USB: при зарядке он блокируется. Громкость в Device должна быть выше нуля.
7. Сними пропеллеры с дрона; ARM выключен, итоговый CH5 около 1000.
   Двойной короткий M включает поиск. Без дрона пары LED чередуются,
   поисковых писков нет (штатное предупреждение потери приёмника возможно).
8. Включи связанный приёмник. Должен появиться короткий периодический писк.
   Измени расстояние/ориентацию или экранируй сигнал телом: при более слабом
   сигнале интервалы увеличиваются. RSSI не гарантирует расстояние в метрах.
9. Повторный двойной M возвращает батарейные LED и прекращает новые поисковые
   писки; один уже поставленный короткий сигнал может доиграть.
10. Выключи дрон: после таймаута данных поисковый писк должен исчезнуть,
    LED — перейти к чередованию пар. После перезапуска пульта поиск выключен.

Сообщи: есть ли писк, меняется ли частота, выключается ли двойным M,
сохранились ли обычные предупреждения/триммеры. При проблеме сохрани UART
и описание поведения. Возврат через доступный загрузчик выполняется тем же
способом файлом 0.6 из recovery. Если загрузчик недоступен, данный архив
не гарантирует восстановление без разборки. Полётные проверки этой версией
не заменяются: сначала стенд, каналы, ARM/disarm и failsafe.

Официальный конфигуратор:
https://radiomaster-rc.github.io/RM-Web-Page/Connection.html
