# RadioMaster T8L DroneFinder 1.0

Неофициальная модификация T8L Controller v1.7 с поиском связанного дрона.

- Двойное короткое нажатие M включает и выключает поиск.
- Четыре светодиода показывают уровень RSSI.
- При усилении сигнала поисковый писк учащается; при отсутствии свежих данных он прекращается.
- Сохранены штатные звуковые предупреждения; при занятой звуковой очереди поисковый писк пропускается.
- В ZIP включены инструкция, исходники, тесты и образы возврата.

Для прошивки выбирайте **T8L_v17_DroneFinder_1.0.bin** (96 844 байта) через
официальный WebUI → Firmware Update → **T8L Controller**.
Полная инструкция: FIRST_TEST_RU.md в архиве или репозитории.

базовая строка версии контроллера остаётся v1.7.

с заглушками штатных функций. Установка предыдущей сборки 0.6 подтверждена

проверено. Перед использованием выполните стендовую проверку из инструкции.
